# Personal Finance Analyzer

A Python project that analyzes financial transactions
from a CSV file.

## Features

- Calculates total income
- Calculates total expenses
- Calculates balance
- Calculates saving rate
- Shows category-wise expenses
- Finds the highest expense category
- Shows monthly expenses

## Technologies

- Python
- CSV

## How to Run

1. Make sure Python is installed.
2. Keep `app.py` and `csv2.csv` in the same folder.
3. Run:
python app.py
